# La Félicità — site vitrine

Site public du restaurant La Félicità (Furdenheim, 67) : accueil, carte, suggestions, réservation et horaires.

Il est branché sur l’application [Felicita-suggestion](https://github.com/HamidBersi/Felicita-suggestion), celle qui sert l’écran en salle et le menu QR.

- **Suggestions.** La rubrique du site ouvre le tableau en direct. Ce que l’équipe publie sur le téléphone est ce que le client voit, le même contenu que l’écran en salle.
- **Menu.** La page carte lit la carte salle de Felicita-suggestion. Un plat, un prix ou une rupture modifié là-bas apparaît ici dans la minute. Un plat retiré n’est plus affiché.

## Stack

**Next.js 16** · React 19 · TypeScript · Tailwind CSS 4 · next-intl

Pages : `/` (accueil) · `/menu` · `/suggestions` · `/reserver` · `/horaires`
